# دعوة زفاف سينمائية رقمية فاخرة | Luxury Cinematic Wedding Invitation

موقع دعوة زفاف رقمية تفاعلية سينمائية مبني بأحدث تقنيات الويب: **React 19 + TypeScript + Vite + Tailwind CSS v4 + GSAP (ScrollTrigger) + Lenis**.

تم تصميم الموقع وتطويره وفق معايير الوكالات العالمية الكبرى والتصميم التحريري الراقي (*Luxury Editorial & Stationery Design*) مع روح الأصالة والأناقة العربية ودعم كامل لاتجاه القراءة من اليمين إلى اليسار (RTL).

---

## ✨ المميزات الرئيسية | Key Features

1. **المشهد الأول (الغلاف والمظروف ثلاثي الأبعاد - 3D Envelope):**
   - تصميم مظروف كلاسيكي فاخر بطبقات ورقية ونقوش ذهبية.
   - ختم شمعي ملكي يحمل الحرفين الأولين من اسمي العروسين (`ع & ي`).
   - فتح تفاعلي للمظروف وطي الغطاء ثلاثي الأبعاد مع خروج بطاقة الدعوة عبر التمرير (Scroll Progress) أو بالضغط على زر "افتح الدعوة".

2. **المشهد الثاني (تقديم العروسين - Couple Reveal):**
   - ظهور متدرج للعروسين مع بطاقات هندسية مزدوجة الحواف (*Double-Bezel Architecture*).
   - خطوط عربية تراثية ملكية (*Aref Ruqaa*) وخطوط لاتينية فاخرة (*Cormorant Garamond*).

3. **المشهد الثالث (المعرض السينمائي - Cinematic Gallery):**
   - صور فوتوغرافية تحريرية بزوايا احترافية وتأثيرات عمق وحركة خفيفة (*Parallax*).
   - نصوص اقتباسات رومانسية رقيقة تظهر مع تقدم التمرير.
   - دعم بدائل بصرية ذكية عند انقطاع الاتصال أو بطء تحميل الصور.

4. **المشهد الرابع (الموعد والعد التنازلي الحي - Date & Live Countdown):**
   - إعلان موعد الزفاف بالهجري والميلادي واليوم والساعة.
   - عدّاد رقمي دقيق يحسب الأيام والساعات والدقائق والثواني في الزمن الفعلي.
   - زر إضافة الحدث لتقويم Google بنقرة واحدة، وزر تنزيل ملف `.ics` لحفظ الحدث في تقويم هواتف Apple و Outlook.

5. **المشهد الخامس (الرسالة الشخصية والآية القرآنية - Personal Message):**
   - مساحة هادئة ذات عمق عاطفي تحتضن الآية الكريمة: *(وَمِنْ آيَاتِهِ أَنْ خَلَقَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجًا...)*.
   - رسالة محبة من عائلتي العروسين بدعوة الأهل والأحباب وتوقيع العائلتين.

6. **المشهد السادس (تفاصيل المكان والمراسم - Wedding Details):**
   - اسم القصر والقاعة والعنوان التفصيلي.
   - زر مباشر لفتح الموقع بدقة في تطبيق خرائط Google في نافذة جديدة آمنة.
   - جدول البرنامج الزمني (الاستقبال، الزفة، العشاء الملكي، الاحتفال).
   - تنويه خدمة ركن السيارات (*Valet Parking*) وملاحظة الزي الرسمي (*Dress Code*).

7. **المشهد السابع (تأكيد الحضور - Interactive RSVP via WhatsApp):**
   - خيارات واضحة لتأكيد الحضور أو الاعتذار بلباقة.
   - تحديد عدد المرافقين، وإمكانية إرفاق كلمة أو دعاء طيب للعروسين.
   - معاينة فورية حية لنص الرسالة العربية المنسقة.
   - توجيه فوري لتطبيق WhatsApp مع تشفير وترميز النص بدقة ودون الحاجة لأي خادم أو قاعدة بيانات خارجية.
   - شفافية كاملة وتوضيح بأن البيانات ترسل مباشرة للمنظمين عبر واتساب.

8. **المشهد الثامن (الخاتمة والتنقل السريع - Closing Scene):**
   - ختم العروسين ودعاء مبارك للضيوف.
   - روابط وصول سريع لتفاصيل المكان أو الصعود لأعلى الصفحة.
   - مشغل صوتي محيطي عائم (*Web Audio Ambient Soundscape*) يعزف نغمات هادئة للمناسبة دون أي ملفات خارجية.
   - شريط تنقل عائم زجاجي (*Floating Island Navigation*) متزامن مع التمرير.

## 🚀 التشغيل والتطوير | Getting Started

### 1. تثبيت الحزم (Install Dependencies)

```bash
npm install
```

### 2. تشغيل بيئة التطوير (Start Dev Server)

```bash
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

### 3. بناء المشروع للإنتاج (Production Build)

```bash
npm run build
```

### 4. معاينة نسخة الإنتاج محلياً (Preview Build)

```bash
npm run preview
```

## ⚙️ تخصيص بيانات الزفاف | Customization Guide

توجد جميع تفاصيل وبيانات الحفل في ملف إعدادات موحّد ومركزي:
📁 `src/config/invitation.ts`

### ١. تعديل أسماء العروسين والحروف الأولى
```ts
couple: {
  groom: {
    name: 'عمر',
    fullName: 'عمر أحمد الشريف',
    title: 'العريس',
    father: 'أحمد الشريف',
  },
  bride: {
    name: 'ياسمين',
    fullName: 'ياسمين خالد المنصوري',
    title: 'العروس',
    father: 'خالد المنصوري',
  },
  monogramArabic: 'ع & ي',
  monogramLatin: 'O & Y',
}
```

### ٢. تعديل موعد الحفل (لتحديث العد التنازلي)
```ts
event: {
  date: '2026-11-20T19:00:00', // صيغة ISO YYYY-MM-DDTHH:mm:ss
  dateArabicFormatted: '٢٠ نوفمبر ٢٠٢٦',
  dayOfWeekArabic: 'يوم الجمعة',
  timeArabicFormatted: 'السابعة مساءً',
  hijriDateFormatted: '١١ جمادى الأولى ١٤٤٨ هـ',
}
```

### ٣. تعديل مكان الحفل ورابط خرائط Google
```ts
venue: {
  name: 'قصر البارون إمبان الأثري',
  hall: 'حديقة القصر الملكية',
  address: 'شارع العروبة، مصر الجديدة',
  city: 'القاهرة',
  country: 'مصر',
  googleMapsUrl: 'https://maps.app.goo.gl/9uG5eQ5n4qY8t7vE7',
  valetAvailable: true,
}
```

### ٤. تعديل رقم الواتساب لاستقبال تأكيدات الحضور (RSVP)
قم بتعديل الرقم بصيغته الدولية دون أي مسافات أو علامة `+`:
```ts
rsvp: {
  whatsappNumber: '201012345678', // مثال: كود الدولة 20 متبوعاً بالرقم
  deadlineText: 'نرجو تأكيد الحضور قبل ١ نوفمبر ٢٠٢٦',
}
```

### ٥. تغيير الصور
يمكنك استبدال روابط الصور بروابط مباشرة عالية الجودة أو صور محلية تضعها في مجلد `public/` أو `src/assets/`:
```ts
photos: {
  hero: 'https://images.unsplash.com/...',
  coupleRevealGroom: 'https://images.unsplash.com/...',
  coupleRevealBride: 'https://images.unsplash.com/...',
  gallery: [ ... ]
}
```

## 🌐 النشر على Vercel | Deployment to Vercel

المشروع مُهيأ بالكامل للنشر الفوري على منصة **Vercel**:

1. ارفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git init
   git add .
   git commit -m "feat: luxury cinematic wedding invitation"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. ادخل إلى لوحة تحكم [Vercel](https://vercel.com).
3. اختر **Add New Project** وحدد مستودع المشروع.
4. إعدادات البناء الافتراضية متوافقة تلقائياً:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. اضغط على **Deploy** وسيعمل موقع الدعوة مباشرة مع شهادة SSL مجانية وسرعة فائقة حول العالم.
