# دعوة زفاف سينمائية رقمية فاخرة | Luxury Cinematic Wedding Invitation

موقع دعوة زفاف رقمية تفاعلية سينمائية مبني بأحدث تقنيات الويب: **React 19 + TypeScript + Vite + Tailwind CSS v4 + GSAP (ScrollTrigger)**.

تم تصميم الموقع وتطويره وفق معايير الوكالات العالمية الكبرى والتصميم التحريري الفاخر (*Luxury Editorial & Stationery Design*) مع روح الأصالة والأناقة العربية، والالتزام الصارم بالضوابط الشرعية الإسلامية للمحتوى والصور، وتجربة تمرير طبيعية وفورية 100% (*Native Responsive Scrolling*).

---

## ✨ المميزات والتحسينات الرئيسية | Key Features

1. **تجربة التمرير الطبيعية والفورية (Native Responsive Scrolling):**
   - إزالة أي تأخير أو ثقل في التمرير، مع استجابة فورية لعجلة الفأرة، لوحة اللمس (Trackpad)، وإيماءات اللمس على الهواتف.
   - تحريك سلس وسريع يعتمد على التتبع المباشر بدون تأخير زمني مصطنع (`scrub: true`).
   - إلغاء التثبيت الشاق في الهواتف لضمان سلاسة التمرير التلقائي.

2. **الالتزام الكامل بالضوابط الإسلامية (Strict Islamic Content Guidelines):**
   - الموقع صامت بالكامل (خالٍ تماماً من الموسيقى أو المؤثرات الصوتية).
   - الصور المختارة تركز على عمارة القصر التاريخية، وباقات الزهور الطبيعية البيضاء، وتفاصيل خواتم الزفاف، والديكور الملكي الراقي، دون أي صور تخالف الحشمة الشرعية.

3. **حفظ الموعد في التقويم (Calendar Integration):**
   - خيار الإضافة المباشرة إلى **Google Calendar** برابط منسق يشمل التوقيت، الموقع، والوصف.
   - خيار تنزيل ملف تقويم قياسي **`.ics`** متوافق مع هواتف iPhone (Apple Calendar) و Outlook دون الحاجة لأي خادم خلفي.

4. **المشهد الأول: الغلاف والمظروف ثلاثي الأبعاد (3D Envelope):**
   - تصميم مظروف ملكي فاخر بطبقات ورقية ونقوش ذهبية مع ختم شمعي ملكي (`ع & ي` / `O & Y`).
   - فتح تفاعلي للمظروف عبر التمرير الطبيعي أو بالضغط المباشر على زر "افتح الدعوة".

5. **المشهد الثاني: تقديم العروسين (Couple Reveal):**
   - بطاقات تقديم متناسقة بنظام الحواف المزدوجة (*Double-Bezel Architecture*) للعريس عمر أحمد الشريف والعروس ياسمين خالد المنصوري.

6. **المشهد الثالث: المعرض السينمائي (Cinematic Architecture & Atmosphere):**
   - لقطات معمارية وتفاصيل ليلية لقصر البارون إمبان وحدائقه مع اقتباسات شعرية هادئة.

7. **المشهد الرابع: الموعد والعد التنازلي الحي (Date & Live Countdown):**
   - إعلان التاريخ بالهجري والميلادي واليوم والوقت بدقة.
   - عداد تنازلي دقيق ولحظي للأيام والساعات والدقائق والثواني.

8. **المشهد الخامس: الرسالة الشخصية (Personal Message):**
   - الآية الكريمة: *(وَمِنْ آيَاتِهِ أَنْ خَلَقَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجًا لِّتَسْكُنُوا إِلَيْهَا وَجَعَلَ بَيْنَكُم مَّوَدَّةً وَرَحْمَةً)* وتوقيع عائلتي العروسين.

9. **المشهد السادس: تفاصيل الحفل والبرنامج والموقع (Venue & Details):**
   - قصر البارون إمبان الأثري بالقاهرة مع زر فتح خرائط Google في نافذة آمنة.
   - جدول البرنامج الزمني (الاستقبال، الزفة، العشاء الملكي، وتقطيع التورتة).
   - تنويهات خدمة ركن السيارات (*Valet Parking*) ومواصفات الزي الرسمي المحتشم.

10. **شريط التنقل السريع العائم (Floating Navigation):**
    - شريط زجاجي عائم يتيح الانتقال الفوري بين المشاهد المختلفة بنقرة واحدة.

## 🚀 التشغيل والتطوير | Getting Started

### 1. تثبيت الحزم (Install Dependencies)

```bash
npm install
```

### 2. تشغيل بيئة التطوير (Start Dev Server)

```bash
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

### 3. تشغيل اختبارات الوحدة (Run Unit Tests)

```bash
npm test
```

### 4. بناء المشروع للإنتاج (Production Build)

```bash
npm run build
```

### 5. معاينة نسخة الإنتاج محلياً (Preview Build)

```bash
npm run preview
```

## ⚙️ تخصيص بيانات الزفاف | Customization Guide

توجد جميع تفاصيل الحفل في ملف الإعدادات المركزي:
📁 `src/config/invitation.ts`

- **بيانات العروسين:** أسماء العروسين، أسماء العائلات، والأحرف الأولى.
- **الموعد والتقويم:** تاريخ البداية والنهاية بصيغة ISO، والمنطقة الزمنية (`Africa/Cairo`).
- **المكان وخرائط Google:** اسم القاعة، العنوان، ورابط خرائط Google.
- **الصور الفوتوغرافية:** روابط صور العمارة والزهور والخواتم.

## 🌐 النشر على Vercel | Deployment to Vercel

1. ارفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git init
   git add .
   git commit -m "feat: luxury cinematic wedding invitation"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. في لوحة تحكم [Vercel](https://vercel.com)، اختر **Add New Project**.
3. الإعدادات الافتراضية:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. اضغط **Deploy**.
